# File 24 0.99.0 — Data-Flow and Ownership Matrix

- Native owners create and mutate domain records.
- File 24 receives versioned, minimized manifests/events/assertions.
- Security events are bounded evidence projections, not the native business truth.
- PII, clinical charts, messages, identity evidence, payment credentials and private media remain with their native owners.
- File 24 stores opaque references to private evidence and dispatches privacy operations to owner handlers.
- Caches, search indexes, reports and Trust Center output are derivative and never grant authorization.
- External providers receive only approved purpose-bound fields; region, retention, deletion and exit evidence are recorded separately.
