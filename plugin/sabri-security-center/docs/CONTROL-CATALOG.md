# File 24 0.99.0 — Control Catalog Constitution

The executable control repository supports stable control keys, framework mapping, owner, state, evidence, last-test time, optimistic concurrency, exclusive write leases, audit-bound rollback and risk-acceptance governance.

Control families cover governance, identity/access, application/API, uploads/private delivery, database/integrity, privacy/retention, vendor/supply chain, monitoring/detection, incident response, resilience/recovery and release assurance. Framework labels may map to NIST CSF 2.0, NIST SP 800-53, NIST SP 800-61, NIST SP 800-218, NIST Privacy Framework, OWASP ASVS/API/SAMM and approved WordPress guidance. A framework label is not a certification claim.
