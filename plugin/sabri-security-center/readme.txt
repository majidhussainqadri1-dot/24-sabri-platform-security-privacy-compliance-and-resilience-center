Central governance and assurance control plane for the Sabri Social Homeopathy Platform.

== Description ==

Foundation 0.25.1 provides a private Security Center dashboard, bounded module manifests and audit events, risk/incident/control foundation workflows, privacy-request orchestration, advisory security-state requests, system checks, non-destructive repair, and sanitized REST status/Trust Center payloads.

It does not replace native-module authorization, File 00 identity, File 20 enforcement, hosting security, legal counsel, backups, or independent security testing.

== Installation ==

1. Install on staging only.
2. Activate the plugin and verify the schema/capability checks.
3. Confirm the correct operational roles have explicit File 24 capabilities.
4. Confirm File 00 and File 20 are detected without bypassing their native ownership.
5. Register companion-module manifests.
6. Connect real external logging and backup/restore evidence adapters.
7. Run Security Center checks and the non-destructive repair only when needed.
