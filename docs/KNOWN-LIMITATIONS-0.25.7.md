# Known Limitations — Foundation 0.25.7

- No claim of production readiness, certification, unhackability or audited end-to-end encryption.
- File 00 step-up verification requires the approved runtime contract `smc_verify_step_up_assertion`; absent identity authority causes approval and reconciliation to fail closed.
- No raw incident, legal, vendor-contract, key or backup-location evidence is stored in the public plugin repository or bounded metadata tables.
- Real Hostinger fresh activation, 0.25.6→0.25.7 upgrade, rollback, File 00/File 20 end-to-end adapters, external logging, browser/accessibility acceptance and provider behavior require staging access.

- Independent penetration testing, a real backup/restore rehearsal and measured RPO/RTO remain mandatory before production approval.
- Live deployment, production smoke testing, monitoring, support ownership, incident drills and operational acceptance are later status gates.
